## Общие сведения о программе
СуперЗавуч - это современное программное обеспечение, предназначенное для автоматического составления расписания уроков в школах, лицеях и колледжах. Программа позволяет создать сложное, сбалансированное расписание всего за несколько минут, избавляя завуча от рутинной работы.

Основная цель программы - взять на себя всю рутину по составлению расписания занятий: быстро, с минимумом действий со стороны пользователя и с максимально качественным итоговым результатом.
Программа доступна для скачивания на официальном сайте, там же находится полная документация по использованию.

## Ключевые возможности
СуперЗавуч предоставляет широкий набор функций для работы с расписанием:

Автоматическое составление расписания без конфликтов - эффективный алгоритм распределяет нагрузку за несколько минут.
Работа с профильными классами и группами - возможность делить классы по профилям и указывать соответствующие предметы.
Управление кабинетами - группировка кабинетов и закрепление их за определёнными уроками.
Поддержка индивидуальных учебных планов - создание комбинированного расписания для отдельных учащихся (сочетание классных и индивидуальных занятий).
Заморозка уроков - фиксация определённых уроков в нужное время, которые не будут изменяться алгоритмом.
Масштабируемость - программа позволяет работать с до 1000 учителей, классов и учебных кабинетов одновременно.
ИИ-ассистент - встроенный помощник для объяснения работы программы, работы с расписанием и импорта данных из различных форматов.
Экспорт в Excel - быстрое сохранение готового расписания в разных форматах.

## Технические детали и алгоритм
Архитектура: интерфейс программы написан на Python 3.11 с использованием библиотеки PyQt5. Алгоритм составления расписания реализован на C++ для достижения высокой производительности.
Алгоритм: в основе лежит метод имитации отжига (температурный отжиг) с использованием графов. Алгоритм минимизирует стоимость расписания, учитывая количество окон у классов и учителей, равномерность распределения сложности предметов, особенности профильных классов и другие параметры.

Производительность: в качестве примера автор приводит составление расписания для школы с 80 учителями и 40 классами за 2 минуты, при этом в расписании оказалось около 130 окон у учителей (в среднем 2 окна в неделю).

## Пошаговая инструкция по использованию
Интерфейс программы разделён на 11 последовательных меню. Пользователю рекомендуется проходить по ним по порядку, заполняя требуемую информацию:

Настройки - ввод базовых параметров: количество рабочих дней, максимальное количество уроков, количество параллелей и т.д. Для каждого предмета указывается имя и сложность, для каждой параллели — количество классов и смена обучения.
Классы - для каждого класса выставляется недельное количество уроков по предметам.
Учителя - задаются учителя, их свободное время, предметы и классы, в которых они преподают, а также кабинеты для проведения уроков.
Предметы - задаются уроки, которые могут проводится в один и тот же день в классе, это таблица где на пересечении двух уроках ставится могут ли эти два урока пересекатся (зелёный) или нет (красный)
Кабинеты - создание групп кабинетов (например, группа Английский язык) для привязки к определённым урокам.
ИИ - меню для работы со встроенным ИИ-ассистентом: он может объяснить работу программы, помочь изменить расписание или импортировать его из многих форматов.
Константы - установка замороженных уроков для определённых классов в нужное время (эти уроки не будут изменяться алгоритмом).
Группы - создание групп для работы с профильными классами и индивидуальным обучением.
Запуск - настройка весов алгоритма (важности каждого параметра) и непосредственный запуск процесса составления расписания.
Просмотр - просмотр только что составленного расписания относительно классов и относительно учителей.
Экспорт - указание временных промежутков уроков для отображения в таблице и экспорт расписания в Excel (отдельно для учителей и классов).
