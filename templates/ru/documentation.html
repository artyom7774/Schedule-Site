Полная документация по использованию программы

Начало

СуперЗавуч - это инструмент, который помогает организаторам образовательного процесса формировать расписание с учётом множества ограничений: нагрузки учителей, доступности кабинетов, сложности предметов и других параметров

01

Установите программу

Скачайте последнюю версию приложения и запустите программу

02

Заполните данные

Заполните вкладки последовательно: настройки > классы > кабинеты > учителя

03

Запустите генерацию

Нажмите кнопку "Запуск" и дождитесь построения расписания

Структура программы

Интерфейс разделён на 10 логических вкладок. Работа с проектом идёт последовательно - от базовых настроек до экспорта готового расписания

Настройки > Классы > Кабинеты > Учителя > ИИ
Ввод исходных данных, импорт и редактирование данных с помощью ИИ
Константы > Группы
Ввод определённых уроков и создание групп & профилей
Запуск > Просмотр > Экспорт
Создание, проверка и экспорт расписания в нужные форматы

Настройки

В настройках указываются базовые настройки программы

Базовые настройки

В настройках указывается количество дней в неделе, уроков в день, количество параллелей, предметов и смен

Также указывается, сколько уроков первой смены пересекают уроки второй смены

Учебные предметы

Для каждого учебного предмета указывается его имя и сложность

Параллели

Для параллели указывается количество классов и смена, в которой учится параллель

Классы

В данном меню для каждого класса определяется сколько раз каждый предмет будет проходить в неделю

Классы

Для каждого класса и предмета указывается сколько раз этот предмет проводится в неделю

Кабинеты

В данном меню определяются кабинеты и их группы

Список групп кабинетов

Возможность удалять и добавлять группу в список

Кабинеты

Для каждой группы определяются кабинеты, входящие в неё

Можно добавить новый кабинет или выбрать из уже добавленных

Учителя

Во вкладке учителей указываются все учителя, их учебные предметы и свободное время

Список учителей

Возможность удалять и добавлять учителей в список

Доступное время для уроков

Для определённого учителя и смены вы можете выбрать, на каких уроках учитель может работать

Зелёным цветом указывается, что учитель может проводить урок в данное время

Учебные предметы

Для определённого учителя выбираются предметы, которые он будет вести

Для каждого предмета выбираются классы, в которых данный учитель будет проводить данный урок

Кабинеты

Для каждого предмета указывается приоритет групп кабинетов, в которых может проводиться урок

Также можно указать, что предмет не требует кабинета (он не будет учитываться алгоритмом)

Искусственный интеллект

ИИ-помощник, позволяющий удобно работать с проектом

Интерфейс

Интерфейс позволяет общаться с ИИ, давать файлы на обработку

Возможности

ИИ может отвечать на вопросы пользователя, вопросы по переданным ему файлам

По запросу ИИ может импортировать в проект данные из данного файла

Файлы

Допустимые форматы файлов, которые может обработать ИИ: .db; .sqlite; .sqlite3; .xlsx; .xls; .txt; .csv; .json; .md; .markdown; .html; .xml; .pdf; .docx

Константы

С помощью данного меню можно заморозить определённый урок в данное время для класса

Константы

Для определённого класса и времени выбирается урок, который должен проводиться в данное время

Группы

Разделение класса на отдельные группы

Группы

Позволяет для каждого класса создать группу. Для каждой группы выбираются предметы, которые будут проводиться для этой группы

С помощью групп можно создавать профильные классы и работать с индивидуальным обучением

Запуск

Позволяет запустить алгоритм создания расписания

Алгоритм

Алгоритм основан на температурном отжиге на графе

Каждое расписание, созданное алгоритмом, оценивается по ряду критериев, каждый из которых умножается на множитель в левом меню

Задача алгоритма - минимизировать полученную оценку

Множители

Одинаковые уроки - определяет, сколько баллов добавляется при двух и более одинаковых уроках в один день для класса

Неверное количество уроков по дням - сколько баллов добавляется, если класс имеет неравное количество уроков в разные дни

Пустые окна в уроках - сколько баллов добавляется за каждый пропуск в расписании класса

Дни по сложности - сколько баллов добавляется, если класс имеет неравномерную сложность уроков в разные дни

Свободное время учителя - сколько баллов добавляется за каждый пропуск в расписании учителя

Бонус за группу - сколько баллов отнимается за каждый урок с несколькими группами одновременно

Пересечение уроков по сменам - сколько баллов добавляется за каждое пересечение уроков по сменам в расписании учителя

Окна в группах - сколько баллов добавляется за каждый урок, где одна из групп не имеет урока, но после имеет ещё уроки

Запуск

После завершения, вы сможете посмотреть и экспортировать полученное расписание
